# Solace Shaders

A calm, smooth cartoon shaderpack for **Minecraft 26.3** on **Iris** (with Sodium).
All GLSL is written from scratch. Closed source, All Rights Reserved.

Download: [Modrinth](https://modrinth.com/shader/solace-shaders) · [GitHub Releases](https://github.com/daemon-tech/solace/releases)

## Features
- Soft cel-shaded lighting with adjustable bands and edge softness
- Thin outlines with colour, strength and distance fade
- Contact-hardening soft shadows, ambient occlusion, rim light
- Banded gradient sky, soft puffy clouds, stylized sun, moon and stars
- Stylized turquoise water with depth gradient, reflections, shore foam and caustics
- Weather, wet ground, light shafts, bloom and layered fog
- Warm torch light, own Nether and End looks
- Settings menu with LOW / MEDIUM / HIGH / ULTRA profiles

## Install
1. Install Iris (and Sodium) for Minecraft 26.3.
2. Drop the zip into `.minecraft/shaderpacks/`.
3. Select **Solace** in the Iris shader menu.
